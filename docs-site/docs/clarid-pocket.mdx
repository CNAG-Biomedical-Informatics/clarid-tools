ClarID-Pocket is an Android companion to ClarID-Tools. It scans ClarID QR labels and displays decoded subject or biosample fields directly on the device. Scanning and decoding work offline.

## Install

1. Open the [latest release](https://github.com/CNAG-Biomedical-Informatics/clarid-pocket/releases/latest) on your phone and download the **`.apk`** file.
2. Open the APK. If Android asks, allow installation from the browser or file manager you used, then tap **Install**.
3. Open **ClarID-Pocket**, tap **Scan QR**, and allow camera access.

No Android Studio, computer, USB connection, or account is required.

## Scan and decode

Leave **Entity** and **Format** on **Auto** for routine scanning. Point the camera at a ClarID QR label; the result reports **Detected: Subject** or **Detected: Biosample**, followed by the decoded fields.

If several QR codes are visible, use the centre crosshair to select the intended label. Tap to focus or pinch to zoom.

## Settings and updates

The **gear button** opens Settings. Auto supports subject and biosample identifiers in Human and Stub formats. To override detection, choose **Entity** first and then **Format**.

**Advanced** contains the subject widths. These must match the settings used to create the label; the app does not infer them.

**About → Check for updates** checks published releases on GitHub and opens the download page when a newer version is available. Only this optional check needs internet access. Installing a newer APK signed with the same release key preserves your settings.

## Compatibility and privacy

:::note Current scope
ClarID-Pocket supports **ClarID 0.04** with its bundled codebook. Older specification releases, imported codebooks, and encoding are not supported. See the [specification](/technical-details/specification) and [codebook documentation](/technical-details/codebook-and-schema) for the shared format.
:::

The app stores decoding settings in private Android storage. It keeps no scan history and does not upload scanned identifiers. QR text and decoded results remain in memory.
